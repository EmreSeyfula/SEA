# Задание 3: Реализация, Git и качество на кода

## 1. Реализирана функционалност

Реализирани са:

- Регистрация и вход (ASP.NET Identity)
- Роли (Admin, Teacher, Student)
- CRUD за тестове
- Създаване на въпроси и отговори
- Стартиране на тест
- Предаване на тест
- Изчисляване на резултат
- История на опити

---

## 2. Как работи

1. Потребителят влиза;
2. Избира тест;
3. Системата създава ExamAttempt;
4. Зареждат се въпросите;
5. Потребителят избира отговори;
6. При предаване:
   - проверява се всеки отговор;
   - изчислява се резултат;
   - записва се в базата.

---

### Проблем 2

### Проблем 3
